Set up your notebook

About 15 minutes, done once. Set up only what's below. Everything else gets created when you actually need it.

Set up the minimum, then write today's FIRST: and start it.

The front fills forward with logs, weeks, projects and Later (once needed), in the order you use them. The back fills backward with scratch. When the two meet, start a new volume.

1 Gather

  • A6 bound notebook (the one you have is fine)
  • A pen that stays with it
  • One clip or a ribbon bookmark
  • Your phone calendar

No stickers, washi tape, stencils or second pen colour. Decoration is setup cost.

2 Label the volume

On the cover or spine, write a volume number that you'll never reuse, plus a start date:

01 · Nov 2026–

If you have older notebooks, they're 01, 02 and so on, and this is the next number. Add the end date when you retire it.

3 Inside front cover: the key

• action   × done   > moved   – note
< scheduled/deferred   ○ event
= feeling  ₹ spend  * priority  ! insight
strike = cancelled    @42 = page 42

Capture first. One home per open action.
Link, don't copy. Continue, don't reserve.
Week: • action / @ project session;
  append together. No fixed blocks.
Day × = work happened; task × = done.
Calendar owns timed commitments.
Leave NEXT: when stopping.
Missed days: restart, then rescue.

The only thing you copy from the docs.

4 Page numbers

Pre-numbered? Done. If not, number pages as you reach them, by their physical position. Never renumber.

Only the front needs numbers for now. Leave scratch pages unnumbered.

  • Left: a rolling list of leads, events and waiting. Append as the week changes.
  • Right: one shared pool. Tasks start with •, projects with their page (@42 GPU). Append in any order; reserve no rows.
  • Day • = planned, day × = worked on it; the leading mark says if it's done. Midweek start? Fine.

7 Page 4: today

THU 26 NOV
FIRST: ______________________

Put the clip here. This page is where you'll write today's log.

8 Calendar: two alarms

  • Daily, start of work: "Open notebook → FIRST:"
  • Weekly, e.g. Sunday evening: "Weekly review · 15 min"

9 Give it a home

Beside the laptop while working; with your keys or bag when leaving. Pen clipped to it.

Don't set up

  • Daily pages in advance. Write each date on the day.
  • Reserved pages or blank rows, for projects, Later or task types. Things get space when they arrive.
  • Habit trackers, spending logs, monthly calendars, a future log.
  • A "nicer" copy of earlier pages. Start from where you are.

Later, when a real project appears

Take the next blank page. Write the title, a one-line outcome, the open bullets and a NEXT: line. Then append NAME → page to the index, and give it a week row when it needs time: @42 GPU. That's all.
